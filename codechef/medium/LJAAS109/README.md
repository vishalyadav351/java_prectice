## Problem

### Print Squares

Write a program that utilizes a while loop to print the squares of numbers from 1 to 5.

### Sample 1:
Input
Output

```

```

```
1 4 9 16 25
```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-07-31T14:43:45.898Z  

```java
public class Main {
    public static void main(String[] args) {
        int i = 1; 
        
        while (i <= 5) {
            System.out.print((i * i) + " "); 
            i++; 
        }
    }
}
```
